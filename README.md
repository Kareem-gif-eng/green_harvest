# GreenHarvest — حصاد أخضر

منصة زراعية عربية (RTL) لمصر: المزارع يسجّل محاصيله ويبيع الفائض أو يتبرع به، والجمعيات تطلب التبرعات، والمساعد الزراعي بيجاوب على أسئلة الفلاح، والمدير يتابع المستخدمين.

المشروع مبني على Flask + SQLite + قوالب Jinja. كل المكونات مجانية ومفتوحة المصدر.

## التشغيل

1. ثبّت Python 3.10 أو أحدث (فعّل Add to PATH عند التثبيت).
2. افتح الطرفية داخل مجلد المشروع وشغّل:
   ```
   pip install -r requirements.txt
   ```
3. انسخ `.env.example` إلى `.env` وغيّر `SECRET_KEY` إلى نص طويل عشوائي.
4. شغّل المشروع:
   ```
   python run.py
   ```
5. افتح المتصفح على http://127.0.0.1:5000

قاعدة البيانات `greenharvest.db` بتتنشأ تلقائياً عند أول تشغيل، ولو فيها جداول قديمة بيتم إضافة الأعمدة الجديدة من غير ما تفقد بياناتك.

**مهم:** شغّل المشروع من خلال `python run.py` وافتح العنوان في المتصفح. ملفات الـ HTML ماتتفتحش مباشرة بالدبل كليك لأنها بتعتمد على السيرفر.

## مساعدك الزراعي (Google Gemini)

### إعداد مفتاح Gemini
1. اعمل مفتاح من Google AI Studio: https://aistudio.google.com/apikey
2. افتح ملف `.env` (اللي نسخته من `.env.example`) وضيف السطر ده:
   ```
   GEMINI_API_KEY=ضع_المفتاح_هنا
   ```
3. اختياري: `GEMINI_MODEL=gemini-3.8-flash` (ده الافتراضي، تقدر تغيّره).
4. أعد تشغيل `python run.py`.

**المفتاح سري:** بيتقري من السيرفر بس، ومابيتبعتش للمتصفح ولا بيظهر في أي صفحة أو ملف JavaScript (ده متغطي في الاختبارات). ماتحطوش في Git.

### الاستخدام
- من القائمة اختار **مساعدك الزراعي 🌱**.
- اكتب سؤالك في الخانة.
- اضغط **🖼️ اختار صور** لعدة صور، أو **📷 صوّر بالكاميرا** من الموبايل. تقدر تشوف الصور وتحذف أي صورة قبل الإرسال. الحد: 4 صور في الرسالة، كل صورة أقل من 5 ميجا، بصيغة JPG أو PNG أو WEBP.
- بعد الرد اضغط **🔊 اسمع الرد** عشان يتقرا بصوت عالي، وزر **⏹ إيقاف القراءة** يوقفه.
- الصور بتتخزن مع المحادثة وما تظهرش غير لصاحبها.

### حدود مهمة
- المساعد بيحلل الصور والمعلومات اللي بتبعتها، وبيقولك الاحتمالات، مش تشخيص مؤكد. لو الصور مش واضحة هيطلب صورة أوضح.
- لو المشكلة خطيرة لازم تكلم الإرشاد الزراعي في منطقتك.
- الكتابة بالصوت والقراءة بالصوت بيعتمدوا على المتصفح والجهاز: لو مش مدعومين هتظهرلك رسالة توضح ده.

### الجداول الجديدة
`ai_messages` و`ai_images` بس، وبيتعملوا تلقائياً. الجداول القديمة مش بتتغيّر وبياناتك محفوظة.

## ربط نموذج التشخيص (لسه مش متوصل)

الكود في `app/ai.py`. الدالة `run_ai()` بترجع `None` لو مفيش `AI_API_KEY`، وفي الحالة دي الطلب بيفضل "بانتظار نموذج" ومفيش أي نتيجة مزيفة. لربط مزود حقيقي، نفّذ الاستدعاء داخل الدالة وأرجع قاموس فيه `result` و`confidence` و`advice`.



## الصوت في الموقع

- **القراءة بالصوت**: زر "🔊 اقرأ الصفحة" فوق كل صفحة بيقرأ العناوين والشرح والرسايل بالترتيب، ومعاه إيقاف ووقف مؤقت وسرعة. كل رد من المساعد فيه زر "🔊 اسمع الرد".
- الكود المشترك في `app/static/js/voice.js`، وبيستخدم Web Speech API بتاعة المتصفح، من غير أي خدمة مدفوعة.

## ملاحظات الإنتاج

- استخدم خادم WSGI مثل gunicorn بدلاً من `python run.py`، وHTTPS أمام التطبيق.
- لو كبر حجم البيانات، انقل من SQLite إلى PostgreSQL.
- خزّن `.env` بعيداً عن Git، وغيّر `SECRET_KEY` قبل أي نشر.
- خذ نسخة احتياطية دورية من `greenharvest.db` ومجلد `uploads/`.
